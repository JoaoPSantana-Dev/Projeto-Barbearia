# Trabalho Final da Disciplina de Engenharia de Software 2

O trabalho final da disciplina consiste em definir uma solução de tecnologia na perspectiva de TI para um problema de uma empresa fictícia, sendo que o grupo assume o papel de "dono" da instituição e precisa exercitar conceitos de elicitação de requisitos, escopo e gestão de projetos.

A empresa escolhida pelo grupo foi uma barbearia que estava enfrentando problemas com o a gestão de agendamento de horários de serviços, controle de estoque, escala de seus colaboradores e visualização de faturamento. A equipe conseguiu, através de entrevistas, levantar as problemáticas enfrentadas e as transformar em histórias de usuário. Além disso, elaborou uma possível solução, elicitou os requisitos funcionais e não funcionais do software, definiu a prioridade de cada uma, definiu um custo para o projeto e portou isso para a plataforma de gestão "Jira".
